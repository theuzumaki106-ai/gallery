# Photos Directory

Place your photos and images in this folder (`photos/`).

### Supported Formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`
- `.gif`
- `.avif`
- `.svg`

### Smart Categorization via Filename:
The gallery automatically categorizes your photos based on the filename!

#### Option 1: Prefix with category name
- `nature-lake-sunset.jpg` &rarr; Category: **Nature**, Title: **Lake Sunset**
- `architecture_glass_tower.png` &rarr; Category: **Architecture**, Title: **Glass Tower**
- `street-rain-crossing.jpg` &rarr; Category: **Street**, Title: **Rain Crossing**
- `portraits-sarah.webp` &rarr; Category: **Portraits**, Title: **Sarah**
- `travel-kyoto-shrine.jpg` &rarr; Category: **Travel**, Title: **Kyoto Shrine**

#### Option 2: Bracket tags
- `[Minimalism] Desert shadow.jpg` &rarr; Category: **Minimalism**, Title: **Desert Shadow**
- `[Wildlife] Bengal Tiger.jpg` &rarr; Category: **Wildlife**, Title: **Bengal Tiger**

#### Option 3: Plain filename
- `Mountain Sunrise.jpg` &rarr; Category: **Photography**, Title: **Mountain Sunrise**
